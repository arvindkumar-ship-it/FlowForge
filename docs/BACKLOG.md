# Remaining master-spec gates

This is the release ledger, not a claim that the complete master spec has shipped.

- PostgreSQL partitioned storage, outbox relay, read replicas and cold tier compaction.
- BullMQ/Redis bulkheads, fair tenant semaphores, admission policies and queue reconciliation.
- Distributed schedules/poll triggers, activation sagas, sub-workflows and partial execution.
- OAuth, KMS-backed rotation, MFA, SSO, invitations and password recovery.
- Native provider tool-calling agent loop and integration SDK/community package isolation.
- Binary/object store, data tables, Git sync, external secrets and log streaming.
- WebSocket push, 500+ golden workflows, property fuzzing and failure matrix chaos tests.
- PITR restore drills, KEDA/HA deployment, SBOM and signed/scanned releases.
- Full primitive library, per-state cross-breakpoint screenshot and accessibility coverage.
- Demonstrate the 10M/day throughput and SLOs on declared reference hardware.

The missing companion Blueprint must be reconciled before claiming v1 scope completeness.
